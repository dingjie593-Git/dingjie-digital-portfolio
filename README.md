# 丁洁 · 空间有戏 / Spaces in Play

The original bilingual sample is index.html. The new acting preview is acting.html. Open `index.html` in a browser, press **听我讲 / LET'S PLAY**. The same files can be served by GitHub Pages without a build or external CDN.

Chinese narration, Chinese and English subtitles, three career milestones, original/proposed Fuzhou B2 plan comparison, synchronized emphasis, pause/resume, seek/replay, drawing enlargement, mute and fullscreen.

This is an acting prototype. The temporary voice and source drawings remain the same as the first sample. A transparent 4-by-3 sprite sheet adds 12 acting frames: gaze, head turn, shoulder and elbow movement, pointing, and returning to the audience. Frames are selected from audio time, so pause and seeking preserve the pose. This is limited keyframe animation, not smooth generated video or phoneme-driven lip sync. 48 shops is a proposed count, not a built or operating result.

The narration's timestamps are derived from generated WAV durations. No visitor-time speech service, credentials, analytics or remote fonts are used. All assets are local to this site.
