# 丁洁 · 空间有戏 / Spaces in Play

First working bilingual narrated portfolio sample. Open `index.html` in a browser, press **听我讲 / LET'S PLAY**. The same files can be served by GitHub Pages without a build or external CDN.

Chinese narration, Chinese and English subtitles, three career milestones, original/proposed Fuzhou B2 plan comparison, synchronized emphasis, pause/resume, seek/replay, drawing enlargement, mute and fullscreen.

This is a prototype, not the finished digital-human performance. The voice is temporary. The approved 3D-style character is an image asset; two mouth states follow speech energy, not a full phoneme-driven lip rig. Independent arm gestures and a rotatable clay 3D model are not yet implemented. The source drawings preserve the user's original assets. 48 shops is a proposed count, not a built or operating result.

The narration's timestamps are derived from generated WAV durations. No visitor-time speech service, credentials, analytics or remote fonts are used. All assets are local to this site.
