# 丁洁 · 空间有戏

统一作品集网页，沿用用户确认的暖纸、粗涂鸦标题、手绘大图框与粘土卡通形象。13个讲述单元，64段中文配音，六个项目与软件、影像和收尾。正文来自《作品集多图页面编排与讲稿V2》。所有图面来自原PPT，48间保留方案数量口径。

打开index.html即可本地浏览；GitHub Pages可直接托管。首次点击启动音频，之后可以连续讲述。提供目录、暂停、重播、本页进度、上一页/下一页、静音、全屏、图面放大和PDF下载。滚动或方向键用于翻页，音频时间控制页内表演。

当前角色使用8帧生成的表演素材，呈现目光、抬手、抓取、指示、介绍、推回和收束的定格节奏。它是有限帧网页动画，不是已绑定的3D模型，口型不属于精确音素同步。当前中文配音是本机临时合成声音。自然声音与精细面部演出仍待HeyGen可调用后替换；角色片段、图面与字幕仍会共享播放时间。

源素材不经过生成模型重绘。网页中作品图只做WebP压缩，保持比例；放大查看保留完整图面。影像页提供已知影片网站入口，缩略图不冒充视频原片。

字体为Permanent Marker（Apache 2.0）和ZCOOL KuaiLe（OFL 1.1），许可证随assets打包。没有外部字体、运行时语音API、分析脚本或密钥。

本目录为新增完整版本，不覆盖仓库中的早期试片及已有未提交工作。
