# 丁洁 · 空间有戏

统一作品集网页，沿用用户确认的暖纸、粗涂鸦标题、手绘大图框与粘土卡通形象。13个讲述单元，64段中文配音，六个项目与软件、影像和收尾。正文基于《作品集多图页面编排与讲稿V2》，开场和福州已按新空间设定编排为短段。所有图面来自原PPT，48间保留方案数量口径。

打开index.html即可本地浏览；GitHub Pages可直接托管。首次点击启动音频，之后可以连续讲述。提供目录、暂停、重播、本页进度、上一页/下一页、静音、全屏、图面放大和PDF下载。滚动或方向键用于翻页，音频时间控制页内表演。

主版本采用“数字空间”设定：静态的大幅画报只留在开场页，独立的小全身角色从后面走出，在完整页面和作品素材之间移动。角色跨页保持存在，语音、走位、停顿和姿势共享时间轴；暂停会冻结人物的运动。12帧透明素材包含6帧走路循环以及站立、挥手、指示、拉近、介绍与查看姿势。开场26.32秒、福州25.15秒使用同一Qwen3-TTS Vivian普通话女声，其余页面仍是本机临时配音。角色是二维动画素材，尚非实时绑定3D模型或精准口型。此前的HeyGen Melissa音轨及对应视频已排除；已完成的Vivian半身口型视频与新走动设定不匹配，未强行接入。classic.html保留此前的固定人物布局。

源素材不经过生成模型重绘。网页中作品图只做WebP压缩，保持比例；放大查看保留完整图面。影像页提供已知影片网站入口，缩略图不冒充视频原片。

实体互动规则：走路保持统一地面；履历卡片下缘设可站立凸缘，开场使用蓄力、跳跃和落地动作抵达高处。图纸的位移在检查手部可达并完成接触后才发生，人物与图纸共享位移并在放手前返回。不可达时只指示，图纸不移动。这是人工编排的二维场景，尚非完整3D碰撞或关节约束系统。

字体为Permanent Marker（Apache 2.0）和ZCOOL KuaiLe（OFL 1.1），许可证随assets打包。没有外部字体、运行时语音API、分析脚本或密钥。

本目录为新增完整版本，不覆盖仓库中的早期试片及已有未提交工作。
