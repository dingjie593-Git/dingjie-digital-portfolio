# 东基 · 独立小人舞台排演

入口：`rehearsal-dongji.html`。这是单幕走位与图卡操作分镜，不替换十幕静态作品集。封面与结尾的大人物继续作为页面图像；表演者始终是独立的小比例角色。

## 路线（66 秒）

| 时间 | 表演目的 | 场景响应 |
|---|---|---|
| 0–3 | 从右侧进入，观察落脚点 | 静态舞台保持完整 |
| 3–5 | 接近粘土块、伸手准备 | 暂不触发图卡 |
| 5–9 | 从地面攀到粘土块，站稳 | 使用既有攀爬姿态占位 |
| 9–13 | 转到边框，抬手点主图 | 接触提示在点图时出现 |
| 13–16 | 主图展开，人物退让 | 主图从原位置放大，原图淡出 |
| 16–24.58 | 框角带看树冠，给观众阅读时间 | 图片保持稳定；坐姿用蹲姿占位 |
| 24.58–27 | 起身，拉出构件卡 | 主图让出空间，构件卡从原位置移动 |
| 27–38.855 | 检查弯折与布光 | 主图和构件图并列 |
| 38.855–41 | 从卡片后抽出多视图 | 多视图从已有卡片后方展开 |
| 41–50.33 | 对照顶视、底视、立面与卷帘 | 三张图形成稳定组合 |
| 50.33–53 | 先收多视图，再归位构件与主图 | 图卡依次返回来源位置 |
| 53–61.5 | 交代从投标到落地的参与范围 | 回到原始固定版面 |
| 61.5–66 | 找落脚点、下到地面、挥手离场 | 为下一幕留出空间 |

原讲述是东基现有 44.495 秒录音，按四段放到排演的 13、27、41、53 秒开始播放。攀爬、取卡和归位期间安排无声操作停顿。默认关闭声音，可打开“带原讲述试听”。字幕沿用真实讲稿与原图资料，不添加未核实项目事实。

## 这轮与下一轮

本轮验证位置、顺序、图卡来源与返回、观看留白和讲述时机。角色复用既有透明走路/攀爬姿态；不是最终连续动作、手部抓握、坐姿、重量反馈或口型。下一轮需要按确定路线制作独立坐框角、扶边攀爬、抓纸角、后退、探头、确认结果等姿态，并对齐手脚接触点。

## 控制

### 第二版比例与图片边缘

站立人物的实际可见高度不低于 900 像素舞台的三分之一；画布尺寸随预览整体缩放，人物比例保持一致。足点与接触提示随新尺寸更新。移动图层只包含图片，不再携带粘土边框或原标签；粘土框仍固定在原舞台。图片四边采用渐隐遮罩，并叠加低透明度的边缘柔化层；图纸用同色纸面承接，以保留清楚的线条。原作品集主页面和原始图片文件不改写。
