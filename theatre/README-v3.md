本轮重做十幕构图，保留人物、原始项目材料、讲述脚本与进度线。

新增layouts-v3.js管理各幕各段落几何布局，editorial-v3.css管理页面视觉差异。图注、标题、段落注释与参与说明分别安排。角色仍沿用原动作与配音时序，随新版图面位置更新走位和接触点；这一轮没有声称新增十套独立角色动画。
