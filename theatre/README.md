# 丁洁 · 空间有戏

2026年10月13日自主创作版。10幕、40段统一中文女声，完整中英字幕，六个项目、工作方法与收尾。整场约6分46秒。

点击“跟我走一遍”连续播放；“逐幕”可让每幕结束后停住。滚动、方向键和底栏切换整幕。目录、图纸册、原图放大、PDF、联系入口都保留。打开图纸时暂停，关闭后点播放继续。

角色为已确认的二维粘土风格动作素材，贯穿舞台，约12帧节奏。声音时间驱动走位、姿态、开场履历平台跳跃和纸签拖动；只有实际手部接近纸签时，角色与纸张才一起移动。暂停冻结同一时间轴。不是实时3D模型，尚未完成精准口型。

配音：本地Kokoro v1.1-zh，zf_001中文女声。原Vivian服务用量耗尽；未使用被否定的Melissa音轨。所有音频为随站点保存的MP3，运行时无需语音服务。外语软件名称在配音中使用中文发音表达，字幕保留原称。

项目图取自已核实作品集图面，未经生成模型重绘。原始33间与调整方案48间、茉莉装置范围、平和入口排除、概念与方案阶段区分保留。图纸册记录各项目个人参与。

字体：ZCOOL KuaiLe（OFL）、Permanent Marker（Apache 2.0），许可证随assets保留。

总纲与资料研究见工作区 output/autonomous-theatre/需求与创作总纲.md。完整分镜、双语讲稿、图片编号、动作与实际配音时长见story.json；story.js为浏览器数据副本。原PDF为可下载参考材料。
